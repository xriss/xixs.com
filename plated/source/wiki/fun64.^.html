#^---------------------------------------------------------------------- #^title trim=ends Fun64 #^---------------------------------------------------------------------- #^body form=wiki trim=ends # Fun64 Fun64 is on github. It started with a 4x8 font, not the smallest possible size as the height is mostly whitespace. It is however the smallest size where I am happy with the results and of course 4 and 8 are such satisfyingly round numbers. A fantasy console built on top of /GameCake which is itself built on top of lua. No real hardware restrictions, just a number of suggestions and a fundamental 8x8 graphical building block. Using custom full screen shaders to replicate character based displays. I am currently leaning towards a minimum 256x128 to maximum 256x256 responsive display resolution. This allows full screen coverage of most current display ratios with an aspect between 2:1 and 2:2 with an old school arcade 4:3 screen hitting that 256x192 ZX spectrum sweet spot. Phone screens are annoying, but with this responsive resolution you can hit full coverage in landscape or have a 256x256 square in portrait with the bottom of the screen used for touch controls. But the choice really is yours. Keep the code visible in a single file, everything right in front of you and easy to modify. Pixel art is included within the code as "ascii art" that can be edited by /Swanky-Paint I am trying to recapture the 80s experience of basic listing magazines. Think a Shadertoy style code experience, single file sketches. The design here is very much a response to block coding "training wheels" for kids. Fun64 is the opposite of block coding, Fun64 is all of the text all of the time, making tomorrow seem more like yesterday. #^----------------------------------------------------------------------
